# 写内容与发布

全部操作在本地仓库 `D:\PrivateGithubRepository\aether-weblog` 里做，最后 `git push` 一次就上线。

三条硬规则，先记住：

1. **一篇内容 = 一个文件夹**，文件夹里必须有 `index.md`（不能是 `xxx.md` 单文件）
2. **文件夹名就是 URL**：`content/posts/docker-network-debug/` → `/posts/docker-network-debug/`
3. **图片和 `index.md` 放同一个文件夹**，正文用文件名引用

文件夹名用英文、数字、连字符，别用中文和空格（URL 会被编码，容易 404）。

## 一、新建技术笔记

```powershell
cd D:\PrivateGithubRepository\aether-weblog

# 1. 建文件夹
New-Item -ItemType Directory -Force -Path "content\posts\docker-network-debug" | Out-Null

# 2. 建正文文件
New-Item -ItemType File -Force -Path "content\posts\docker-network-debug\index.md" | Out-Null

# 3. 打开编辑
notepad "content\posts\docker-network-debug\index.md"
```

粘贴这段 front matter，改成你自己的：

```markdown
---
title: "Docker 容器网络排查记录"
date: 2026-10-20T20:10:00+08:00
categories: ["技术"]
tags: ["docker", "网络"]
summary: "容器 ping 不通外网时，我是怎么一步步定位到 iptables 转发链的。"
draft: false
---

## 现象

...

## 排查过程

...
```

字段说明：

| 字段 | 必填 | 作用 |
|---|---|---|
| `title` | 是 | 标题，列表和页面标题都用它 |
| `date` | 是 | 时间，列表按它倒序；必须是 `2026-10-20T20:10:00+08:00` 这种带时区的格式 |
| `categories` | 否 | 分类，目前统一写 `["技术"]` |
| `tags` | 否 | 标签，页面上显示成 `#docker`，点击进标签页 |
| `summary` | 建议 | 一句话摘要，首页、列表、搜索结果都用它 |
| `draft` | 否 | `true` 时只在本地 `hugo server -D` 可见，不会发布 |

## 二、给笔记放图片

```powershell
# 把截图复制进这篇文章的文件夹，文件名用英文
Copy-Item "C:\Users\Jack\Pictures\shot-1.png" "content\posts\docker-network-debug\shot-1.png"
```

正文里用 shortcode 引用：

```markdown
{{</* img src="shot-1.png" alt="iptables 转发链" caption="图注，可省略" */>}}
```

构建时自动做四件事：宽度限制到 1600px、转 WebP、生成 800w/1600w 两档 `srcset`、加 `loading="lazy"`。一张 1MB 的 PNG 出来通常 100–250KB。

写普通 Markdown 也行（`![说明](shot-1.png)`），但那是原图直出，没有压缩和响应式。

图片命名：`shot-1.png`、`shot-2.png`、`arch.jpg`。**不要**中文、不要空格、不要重复名。

| 字段 | 取值 | 作用 |
|---|---|---|
| `medium` | 电影 / 剧集 / 动画 / 综艺 | 列表第一行「类型」筛选 |
| `genre` | 数组，如 `["悬疑","剧情"]` | 列表第二行「剧情」筛选，可多个 |
| `region` | 中国 / 美国 / 日本 / 韩国… | 列表第三行「地区」筛选 |
| `rating` | 0–10，可带小数 | 评分，列表按它从高到低排 |
| `status` | 在看 / 看完 / 重看 / 弃了 | 显示在标题下 |
| `year` | 作品年份 | 和 `date` 不是一回事 |

## 五、本地预览

```powershell
cd D:\PrivateGithubRepository\aether-weblog
hugo server -D
```

打开 <http://localhost:1313>，改文件保存后浏览器自动刷新。`-D` 表示连草稿一起显示。

想只看构建结果不启服务：

```powershell
hugo --minify --gc
# 产物在 public/，可以直接双击 public\index.html 看
```

预览完按 `Ctrl+C` 停掉。

## 七、改、删、草稿

**改内容**：直接编辑 `index.md`，然后走「更新博客」那三条 git 命令。

**改标题**：只改 front matter 的 `title`，URL 不变。

**改 URL**：重命名文件夹（`git mv content\posts\旧名 content\posts\新名`）。旧链接会 404，慎用。

**删一篇**：删掉整个文件夹，push。部署时 rsync 带 `--delete`，线上会一起消失。

**先存草稿**：`draft: true`，本地 `-D` 能看到，push 了也不上线。想发布改成 `false` 再 push。

## 八、发布前检查清单

- [ ] 文件夹名是英文/数字/连字符
- [ ] 有 `index.md`，不是 `xxx.md`
- [ ] `date` 是 `2026-10-20T20:10:00+08:00` 格式
- [ ] `summary` 写了
- [ ] `draft` 是 `false` 或者删掉了
- [ ] 图片在同目录，文件名英文
- [ ] `hugo server -D` 预览过，排版正常

## 九、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 线上没有新文章 | `draft: true`，或 Actions 失败 | 看 Actions 页面红色日志 |
| 列表里排序不对 | `date` 缺失或格式错 | 用带时区的完整时间 |
| 图片 404 | 图片没和 `index.md` 同目录，或用了单文件形式 | 改成文件夹 + `index.md` |
| 图片没被压缩 | 用了 `![](x.png)` 而不是 `{{</* img */>}}` | 换 shortcode |
| 中文文件夹访问 404 | URL 编码问题 | 文件夹改英文 |
| 页面还是旧的 | 浏览器缓存 | `Ctrl+F5` |
| `hugo` 命令找不到 | PATH 没生效 | 重开终端，或 `winget install Hugo.Hugo.Extended` |
