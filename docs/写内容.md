# 写内容与发布（全程点鼠标，不用命令行）

仓库在 `D:\PrivateGithubRepository\aether-weblog`。

用到的两个软件（你机器上都有）：

| 软件 | 干什么 |
|---|---|
| **Typora** | 写 Markdown，粘贴图片会自动存到文章旁边 |
| **VS Code** | 提交 + 推送（图形界面的「源代码管理」面板），也能预览 |

整套流程四个动作：**复制模板文件夹 → 改名 → 写 → 在 VS Code 里点提交推送**。

---

## 一、给 Typora 设一次图片保存位置（只做一次）

Typora →「文件」→「偏好设置」→「图像」，按这样设：

- 「插入图片时」选 **复制图片到指定路径**
- 路径填 `./`
- 勾上「优先使用相对路径」

设完之后，你在文章里 `Ctrl+V` 粘贴截图，图片会**自动存到这篇文章的文件夹里**，并插入 `![](图片名.png)`。不用手动搬文件。

---

## 二、新建一篇技术笔记

### 第 1 步：复制模板

1. 打开资源管理器，进 `D:\PrivateGithubRepository\aether-weblog\模板`
2. 右键 **笔记** 文件夹 → 复制
3. 进 `content\posts\` → 右键 → 粘贴
4. 右键刚粘贴的「笔记」文件夹 → 重命名，改成英文短名，比如 `docker-network-debug`

> 文件夹名就是网址：`docker-network-debug` → `http://111.228.25.195/posts/docker-network-debug/`。
> 只能用小写英文、数字、连字符，不要中文和空格。

### 第 2 步：写内容

进这个文件夹，双击 `index.md`（用 Typora 打开），前几行长这样：

```
---
title: "标题写这里"
date: 2026-10-20T20:30:00+08:00
categories: ["技术"]
tags: ["Docker", "MySQL"]
summary: "一句话摘要，会显示在列表和搜索结果里"
draft: true
---
```

要改的只有四行：

| 行 | 怎么改 |
|---|---|
| `title` | 改成真标题 |
| `date` | 改成今天的日期，格式 `2026-10-20T20:30:00+08:00`（时间随便写，时区别动） |
| `tags` | 标签，可有多个，中英文都行 |
| `summary` | 一句话摘要，列表和搜索结果里显示它 |

然后往下写正文。

### 第 3 步：发布前把草稿关掉

把 `draft: true` 改成 **`draft: false`**。

> 模板默认是 `true`，意思是「草稿」——没改的话推上去也不会显示在网站上。这是保护措施，不是 bug。

---

## 三、往笔记里放图片

**方法一（推荐）**：Typora 里直接 `Ctrl+V` 粘贴截图。图片落到同文件夹，正文自动出现 `![](image-1.png)`。

**方法二**：把图片文件拖进这个文件夹（和 `index.md` 放一起），然后在 Typora 里拖进来或者手写 `![](图片名.png)`。

构建时会自动处理，你不用管：

- 超过 1600px 宽的缩到 1600
- 转成 WebP（1MB 的 PNG 出来通常 100–250KB）
- 生成 800w / 1600w 两档，手机加载小图
- 加懒加载

图片命名建议 `shot-1.png`、`arch.jpg`，别用中文和空格。

---

## 四、新建随笔

1. `模板\随笔` 复制到 `content\essays\`
2. 文件夹改名，比如 `2026-10-20-keyboard`
3. 写 `index.md`，把 `draft` 改 `false`
4. 推送

随笔列表在导航栏「随笔」，按时间倒序，每页 8 篇自动分页。

---

## 五、新建影视

1. `模板\影视` 复制到 `content\media\`
2. 文件夹改名，比如 `sha-qiu-2`
3. 写 `index.md`，改这几项：

| 字段 | 填什么 |
|---|---|
| `title` | 片名 |
| `medium` | 电影 / 剧集 / 动画 / 综艺（列表第一行筛选） |
| `genre` | 数组，如 `["悬疑", "剧情"]`（第二行筛选，可多个） |
| `region` | 中国 / 美国 / 日本 / 韩国（第三行筛选） |
| `year` | 作品年份 |
| `rating` | 0–10，可带小数，列表按它从高到低排 |
| `status` | 在看 / 看完 / 重看 / 弃了 |

4. 海报：把图片存成 **`poster.jpg`** 放进同一个文件夹（名字必须是小写 `poster.jpg`）。不存也行，页面用渐变底 + 片名占位。
5. `draft` 改 `false`，推送。

---

## 六、看效果

**方式一：改完直接推，看线上**（最快，40 秒）

**方式二：本地预览**——双击仓库根目录的 **`预览.bat`**，浏览器会自动打开 <http://localhost:1313>。
改文件保存后页面自动刷新。关掉那个黑窗口就停止。

> 预览窗口里能看到 `draft: true` 的草稿，线上看不到——这就是两者的区别。

---

## 七、发布（在 VS Code 里点）

1. 打开 VS Code →「文件」→「打开文件夹」→ 选 `D:\PrivateGithubRepository\aether-weblog`
2. 左侧点第三个图标「源代码管理」（或按 `Ctrl+Shift+G`）
3. 上面「消息」框里写一句，比如 `post: docker 网络排查`
4. 点 **✓ 提交**（提示要不要暂存全部时选「是」）
5. 点 **同步更改**（Sync Changes）——这就是 push

等 40–60 秒，刷新 <http://111.228.25.195/> 就能看到。

进度也可以看网页：<https://github.com/202367jack/aether-weblog/actions>，绿色对勾 = 发布成功。

## 八、改、删、草稿

| 想做什么 | 怎么做 |
|---|---|
| 改内容 | Typora 打开 `index.md` 改 → VS Code 里提交 + 同步 |
| 改标题 | 只改 `title`，网址不变 |
| 改网址 | 重命名文章文件夹（旧链接会 404，慎用） |
| 删一篇 | 删掉整个文件夹 → 提交 → 同步（线上会一起删） |
| 先存草稿 | `draft: true`，推上去也不显示 |
| 撤回一次发布 | VS Code 源代码管理里对改动点「放弃更改」 |

## 九、发布前检查清单

- [ ] 文件夹名是小写英文/数字/连字符
- [ ] 文件夹里有 `index.md`
- [ ] `title`、`date`、`summary` 都改了
- [ ] `draft: false`
- [ ] 图片和 `index.md` 在同一个文件夹
- [ ] 双击 `预览.bat` 看过，排版正常
- [ ] VS Code 里提交并「同步更改」

## 十、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 线上没有新文章 | `draft` 还是 `true`，或 Actions 失败 | 改 `false` 再推；看 Actions 页面红色日志 |
| 图片不显示 | 图片不在 `index.md` 同目录，或名字大小写不符 | 把图片拖进文章文件夹 |
| 图片很糊/很占流量 | 用了外链原图 | 用同目录图片，构建会自动压缩 |
| 文章列表排序不对 | `date` 没写或格式错 | 照模板格式填 |
| 中文文件夹访问 404 | URL 编码问题 | 文件夹改英文 |
| 页面还是旧的 | 浏览器缓存 | `Ctrl+F5` |
| 双击 `预览.bat` 报找不到 hugo | 没装或 PATH 没生效 | `winget install --id Hugo.Hugo.Extended -e`，然后重开窗口 |
| VS Code 里没有「同步更改」 | 还没提交 | 先点提交，再同步 |
