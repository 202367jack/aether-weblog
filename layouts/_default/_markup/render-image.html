{{- /* 普通 Markdown 图片也走压缩管线：图片是同目录 page bundle 资源时自动转 WebP + srcset */ -}} {{- $dest := .Destination -}} {{- $alt := .Text -}} {{- $title := .Title -}} {{- $res := "" -}} {{- $u := urls.Parse $dest -}} {{- if not $u.IsAbs -}} {{- $name := strings.TrimPrefix "./" $u.Path -}} {{- with .Page.Resources.Get $name -}} {{- $res = . -}} {{- end -}} {{- end -}} {{- if $res -}} {{- $big := $res -}} {{- $small := $res -}} {{- if gt $res.Width 800 -}} {{- $small = $res.Resize "800x webp q82" -}} {{- else -}} {{- $small = $res.Resize (printf "%dx webp q82" $res.Width) -}} {{- end -}} {{- if gt $res.Width 1600 -}} {{- $big = $res.Resize "1600x webp q82" -}} {{- else -}} {{- $big = $res.Resize (printf "%dx webp q82" $res.Width) -}} {{- end -}} {{- else -}} {{- end -}}
