## 我是谁

我是 Aether，南昌大学软件工程 2023 级本科生。方向是 Java 后端，喜欢把学到的东西做成能跑起来的东西——一台服务器、一个可部署的项目，比读十篇文章更容易让我确认自己真的懂了。

这个站点是我的公开笔记本：学习经历、做过的项目、看过的影视，都放在这里。

## 学习经历

### 2023 · 入学，打基础

数据结构、操作系统、计算机网络、数据库原理。这些课当时觉得离"写系统"很远，后来做项目才发现，排查一个慢查询、想清楚一条消息为什么重复消费，靠的都是这些底子。

### 2025 · 从单体到 DDD

做了第一个有完整业务闭环的项目：拼团营销交易系统。试算、锁单、结算、退款，每一步都有边界条件。用六边形架构分层，把营销规则抽成策略+责任链，第一次体会到"设计"和"能跑"是两件事。

### 2026 · AI 工具链与自建环境

开始接触 Spring AI，把文档向量化入库做 RAG 检索，再把发帖、通知这些能力封装成 MCP 工具交给大模型调用。同时买了一台云服务器，从裸机搭到 Nginx + CI/CD。

最大的收获不是记住多少命令，而是明白**每一步为什么这么做**——这也是这个站存在的理由。

## 现在在做什么

- 用 Spring AI 做 RAG 与 MCP 工具服务，把"生成文章 → 发帖 → 通知"串成自动化流程
- 维护一台 4c8g 云服务器：Docker Compose 管中间件，Nginx 托管这个站，push 即发布
- 把踩过的坑写成可复现的步骤，避免第二次踩
