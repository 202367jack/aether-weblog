## 我是谁

Java 后端开发，业余时间折腾服务器。这个站点用来记录学习过程、做过的项目，以及看过的影视。

写东西的原则：只写自己真正做过、踩过、想明白的事。宁可写短，不写自己都不信的话。

## 学习经历

### 2024 · 从语法到能写接口

Java 基础、集合、并发，然后是 Spring Boot。第一次让一个接口在本机跑起来，返回一个 JSON，那天的兴奋感现在还记得。

### 2025 · 微服务与中间件

开始接触 Nacos、Redis、RabbitMQ、MySQL 调优。问题也变多了：配置中心连不上、消息重复消费、索引不生效。这些坑后来都变成了笔记。

### 2026 · 自建环境与自动化

买了一台云服务器，从裸机开始搭：系统、Docker、中间件、CI/CD。

最大的收获不是记住多少命令，而是明白**每一步为什么这么做**——这也是这个站存在的理由。

## 现在在做什么

- 用 Docker Compose 管理一套中间件，按需启动，不常驻占内存
- 用 Hugo 维护这个站点，内容全在 Git 里，一次 push 完成发布
- 把踩过的坑写成可复现的步骤，避免第二次踩
